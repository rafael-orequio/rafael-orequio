## 🚀 Projetos em destaque

### 🤖 JARVIS — Assistente Pessoal por Voz

Assistente pessoal para Windows desenvolvido em Python, com foco em inteligência artificial, interação por voz e automação de tarefas.

O projeto busca integrar diferentes tecnologias para criar uma experiência de assistência inteligente no computador.

**Principais recursos:**
- 🎙️ Reconhecimento de voz com Whisper.
- 🧠 Integração com a API do Google Gemini.
- 🖥️ Interface visual com HUD 3D.
- ⚙️ Automação de tarefas e interação com o sistema.
- 🌐 Abertura de programas e sites.
- 📊 Monitoramento de recursos do computador.
- 🔐 Ações controladas por permissões e confirmações.

**Tecnologias:** Python, Whisper, Gemini API e tecnologias de interface.
